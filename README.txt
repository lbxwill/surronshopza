SURRONSHOP NETLIFY FIXED DEPLOYMENT

IMPORTANT:
1. Extract this ZIP first.
2. Drag the EXTRACTED folder named lbxparts-netlify-fixed onto Netlify Drop.
3. Do not drag only the ZIP file unless Netlify specifically accepts it.

5. No build command is needed.
